# 1118-1735 动图重编码与卡顿修复报告

2026-11-18 17:04 用户截图反馈「codex 这里的动图怎么这么卡啊」，指向展厅 GPT 分类下 `GPT-5.6 Codex` / `GPT-5.6 Luna Codex` 两张卡片。

用户在三个修复方向中选择 **「重编码动图」**（删重复帧、统一帧率、尺寸归一、压体积），未选择「视口内播放」与「两者都做」。因此本批次**保持 63 张动图全部自动加载并播放**的既有约定，只改素材与渲染层，不改 `sites-data.js`、不下载架任何卡片。

按红线，全程**未对模型页面做复核、评审、评分或 code-reviewer**；所有测量只针对缩略图资源与展厅容器。

## 二、诊断结论（只读实测）

| 排查项 | 实测结果 |
|---|---|
| 是否加载失败 | 否。51 张动图全部 `complete && naturalWidth>0`，`.thumb-anim` 经 `elementFromPoint` 确认盖在静态图上层；连续截屏每次画面都不同，动图确实在播 |
| **主因：素材本身近乎静止** | 63 张动画里 **32 张帧间平均像素差 < 2**。`gpt-5-6-luna-codex.webp` 40 帧平均差仅 **0.25**，39 帧几乎完全相同，仅末帧突然变灰；`gpt-5-6-codex.webp` 8.53，是云与光斑极缓慢渐变。全库 153/1071 个帧间隔接近零变化 |

| 截图里「文字 + 半张蓝天」 | 非加载异常，是 `GPT-5.6 Luna Codex` 页面首屏本身为标题文字 + 下方蓝天 |

## 三、实施

### 3.1 可恢复备份

63 张原始 WebP 全量备份到 `02-TempFiles/backup-webp-1118-1720/`（13 MB，该目录被 `.gitignore` 忽略，不随 `dist` 部署）。加上 git 历史，可随时回滚。

### 3.2 重编码（`03-TempScr/1118-1720-重编码动图.py`）

- 解码原动画 → 白色底合成 alpha → 等比 cover 裁切到 **640×400**（与 `.thumb-wrap` 的 16:10 一致，消除 `object-fit` 裁切差异）。
- **按累计画面变化量均匀重采样 9 个关键帧**：静止段被跳过、突变段被展开，避免「卡住很久然后闪一下」。
- 关键帧两两之间线性插值补 1 帧（含尾→首闭环），共 **18 帧**；`ensure_distinct()` 打散完全相同的相邻帧，防止 WebP 编码器合并成长帧。
- 统一 **83ms/帧（12fps）、loop=0、1.494s 循环**，quality 58 / method 4。
- 低变化素材曾试过把推镜**烘焙进 WebP**，但 `gpt-5-6-luna-codex` 从 48 KB 涨到 159 KB（+228%），故改为零体积的 CSS 方案（见 3.3）；脚本保留 `--motion` 开关但默认关闭。

结果：**12.12 MB → 6.75 MB（-44%）**，平均 109.6 KB，最小 46 KB、最大 216 KB。61 张为 18 帧；`gpt-6-2-astra`、`mimo-v2-6-pro` 两张被编码器合并了 1 个重复帧（17 帧 + 1 个 166ms 帧），**总循环时长同为 1.494s**，播放行为一致。

### 3.3 CSS 连续运动层（`assets/style.css`）

- 新增 `@keyframes thumb-drift`：10s `ease-in-out` 往返，`scale(1) → 1.025` + 轻微位移，由合成层以 60fps 插值，**零文件体积**；让源页面本身无动画的素材也保持连续位移。
- `@media (prefers-reduced-motion: reduce)` 下关闭动画。
- hover 放大从 `.thumb-wrap img` 移到 `.thumb-wrap` 容器（`.thumb-wrap` 增加 `transition: transform`），避免与动画 `transform` 冲突；实测 `transitionProperty = transform`。
- `assets/app.js`、`sites-data.js`、`index.html`、静态 PNG 全部**未改动**。

## 五、边界与后续

- **素材内容层面**：原本 32 张动图对应的源页面本身几乎没有动画，它们只是「同一页面在不同时间点的截图」。本批次让节奏均匀、帧率统一、体积减半并叠加连续推镜，但**不会凭空产生真实交互动画**。若要让这些卡片真正「页面自己动起来」，需从 `sites/*.html` 重新截交互帧（滚动、状态切换、视角移动），属于另一批工作量。
