# 1119-1425 动图突变修复与评分更新报告

## 一、用户诉求

2026-11-19 14:08 用户给出两张展厅截图，提出两件事：

1. **`GPT-6.2 Astra` 登记 10 分**（截图里该卡片显示「未评分」）。
2. **「所有的你动图突变太大了」** —— 上一批（1118-1735）重编码后的动画在播放时画面跳变明显。

按红线，全程**未对模型页面做复核、评审、评分或 code-reviewer**；10 分是用户指定的登记值，其余测量只针对缩略图资源与展厅容器。

## 二、突变根因

上一版 `1118-1720-重编码动图.py` 采用「按累计画面变化量均匀重采样 9 个关键帧 + 插值补到 18 帧」，把 40 帧素材压成 18 帧、循环从 5.0s 缩到 1.494s。结果是**变化被压缩到更少的帧里、播放又快一倍**，单帧跳变被放大。

| 素材 | 原始 max | 上一版 max |
|---|---|---|
| `deepseek-v4-flash-0424-wb` | 7.78 | **13.74** |
| `qwen-3-8-flash-api` | 6.04 | **9.47** |
| `gpt-5-6-codex` | 5.57 | **8.34** |
| 全库 | max 中位 4.01、`max>10` 共 **20/63** 张 | — |

（帧间差为 160×100 尺度下相邻帧 RGB 平均绝对差。）

## 三、方案迭代（如实记录两次失败尝试）

1. **时间轴均匀插值版**（30 帧 / 100ms / 3s）：闭环写成「末帧硬跳回首帧」，反而制造更大突变（`gpt-5-6-codex` 5.57→17.36），且样本体积涨 66%。修正闭环后仍不理想，3D 素材 max 升到 36.26。**弃用**。
2. **温和保留版**（40 帧原样保留 / 150ms）：40 帧素材的突变确实降回原版水平，但 8 帧的 3D 短素材补帧不足，max 升到 61.13；体积回到 11 MB 级别。**弃用**。
3. **自适应补帧版（最终采用）**：`03-TempScr/1119-1410-平滑重编码动图.py`
   - 长序列（≥20 帧）取**前段连续 24 帧**，避开末尾昼夜/夜间硬切；
   - 相邻帧之间按实测像素差**自适应补帧**，把每一步变化压到 `MAX_STEP=2.5` 以内（单间隔最多 10 帧、总帧数 ≤32+4）；
   - 末尾用同样方式渐变回首帧，循环处无硬跳；
   - 统一 **640×400 / 130ms / loop=0 / quality 45**，帧数按素材自适应 **7~36 帧**；
   - 连续运动感由 CSS 合成层提供，不靠放大帧间变化。

同时把 CSS 推镜减弱：`thumb-drift` 从 **10s / scale 1.025** 改为 **14s / scale 1.012**（`assets/style.css`）。

## 四、评分登记

评分不在 `sites-data.js`，而在 `assets/app.js` 的 `DEFAULT_RATINGS` 预置表（用户 localStorage 手动评分优先）。新增：

```js
'gpt-6-2-astra': 10,
```

该 slug 是 GPT 分类第一张卡片。全新浏览器 profile 实测显示「10 分」、5 颗满星、`rated=true`。**注意**：若某浏览器 localStorage 里曾手动把该条目清成 0，会覆盖默认值，需清除站点存储或重新打分。

| 指标 | 上一版（1118-1735） | 本版 |
|---|---|---|
| 编码方式 | 按变化量重采样 18 帧 / 83ms | 保留原帧 + 自适应补帧 / 130ms |
| 体积 | 6.75 MB | **7.39 MB**（原始 12.12 MB） |
| 尺寸 | 640×400 | 640×400 |

| 样本 `gpt-5-6-codex` max | 8.34 | **3.23** |

剩余 6 张 `max>10` 全部是 3D 昼夜场景（`3d-deepseek-v4-1-flash` 20.19、`3d-deepseek-v4-flash-vision` 18.61、`3d-deepseek-v4-pro` 17.22、`3d-glm-5-3` 13.67、`3d-gpt-6` 10.63）与 `gpt-6-1-sol` 14.46，属于源素材本身的强明暗切换，已通过补帧摊薄但无法完全消除。

规格说明：62 张帧时长为 130ms，1 张因编码器合并了重复帧出现 `130/260ms`，总循环时长不变；帧数自适应不等长，属预期。
