### 2. 所有 WebP 动图自动加载与播放

| 位置 | 调整前 | 调整后 |
|---|---|---|
| `assets/app.js` 卡片模板 | `.thumb-anim` 只有 `data-anim`，无 `src` | 直接带 `src`（`.webp`）、`loading="eager"`、`fetchpriority="low"` |
| `assets/app.js` 事件委托 | `pointerover` 首次悬停才赋 `src` | 移除该懒加载分支 |
| `assets/style.css` | `.thumb-anim { display:none }`，仅 `.site-card:hover` 时显示；hover 时静态图 `opacity:0` | `.thumb-anim { display:block }` 常显并自动循环播放；静态 PNG 保留作加载失败回退；hover 只保留轻微放大 |
